# 💡 Data Engineering HUB

Welcome to the **Data Engineering HUB** – your one-stop destination to master everything you need for a career in data engineering. This repository is designed to help you practice, learn, and grow your technical skills with hands-on daily content, structured topics, and real-world concepts.

---

## 📁 Repository Contents

### 🔹 **Daily Practice**
Sharpen your skills with focused daily exercises across multiple domains essential for a data engineering role:

- 🧠 **Daily DSA** – Data Structures & Algorithms practice to enhance problem-solving skills.
- ⚙️ **Daily PySpark** – Practice distributed data processing and transformations using PySpark.
- 💻 **Daily Shell Scripting** – Automate tasks and get comfortable with command-line scripting.
- 🏗️ **Daily System Design** – Build scalable systems through design principles and real-world scenarios.
- 🐍 **Daily Python Essentials** – Master the fundamentals and core Python concepts used in data pipelines.

### 🔹 **SQL Content**
Structured SQL content and case studies to help you develop strong querying skills and data modeling expertise:

- 📊 **SQL50 Questions** – A curated set of 50+ SQL practice problems covering beginner to advanced queries.
- ⏳ **[Slowly Changing Dimensions](./Slowly%20Changing%20Dimensions/)** – Real-world data warehousing concept with practical examples and types (SCD Type 1, Type 2, etc.).
